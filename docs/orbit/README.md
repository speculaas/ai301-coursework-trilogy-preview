# Aurum System (Copilot v1) — fictional orbital model

Dependency-free HTML Canvas page generated by M365 Copilot (v1, 2026-10-18) from the user's Python/Matplotlib Aurum sketch. **Fictional system** — bodies CHAR, FORTUNE, CRAG, SOLITAIRE / SOLACE, AUGUST, WISP and THE MOTHERSHIP around the central star AURUM. It is *not* the real Solar System; keep this content intact until a later iteration decides on modes.

Installed as an independent sibling of the status boards: `docs/orbit/` (NOT `docs/status/` — putting it in `docs/status/` would overwrite the gitGraph board viewer).

## Customize

Edit the `bodies` array near the top of `app.js`. `radius`, `angle`, `rate`, `size`, and `type` drive the simulation and inspection panel. Light theme is the zip's own `#f6f1e5` paper palette, kept as-is for v1.
